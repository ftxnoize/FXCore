# FXCore
Program files and libraries for the FXCore DSP from Experimental Noize

Files in **Complete_FXC** can simply be run through the assembler, they do not depend on any other files

Files in **Dependent_FXC** are dependent on one or more library files in **Libraries** and must be run through the preprocessor before the assembler

Files in **GooeyCore_GCF** are GooeyCore files and are dependent on one or more of the library files
